# Workout Tracker API

## Description
A Flask REST API for managing workouts and exercises. The application allows users to create, view, update, and delete workouts and exercises.

## Technologies Used
- Python
- Flask
- Flask SQLAlchemy
- Flask Migrate
- Marshmallow
- SQLite
